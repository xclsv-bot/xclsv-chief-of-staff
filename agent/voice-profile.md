## Global defaults (all registers)

- Short. Say the thing, then stop. No filler pleasantries, no corporate boilerplate
  ("per my last email," "hope this finds you well" — never).
- Direct, positive, human. Warm without gushing; no over-apologizing.
- Match the thread's existing tone and language when replying in-thread.

## Registers (to be distilled from the corpus)

| Register | Starting assumption |
|---|---|
| Established partner | First-name, casual-professional, gets to the point in the first line |
| New contact | Slightly fuller framing, still brief; credibility without a pitch wall |
| Internal team (Anna, Andrea, dev) | Terse, informal, action-first |
| Nudge / follow-up | 2–3 sentences, names the specific open item, no apology for chasing |
| Scheduling | Concrete options over open-ended asks |
| Declining / deferring | Kind, unambiguous, leaves the door open only when Zaire means to |

## To be observed from the corpus

- Greeting and closing norms per relationship (when he skips them entirely).
- Typical length by situation; how he says no; how he chases; how he defers a number.
- Characteristic phrasings worth reusing (and any tics to avoid overusing).

## Corpus rules (binding even for this stub)

- Retrieved examples condition **style only** — tone, structure, length. Facts, numbers,
  and commitments in old emails are precedent for *how* Zaire writes, never for *what*
  a draft may claim (hard rule 3, `ARYA.md`).
- Excluded threads/contacts/keywords (legal, capital, personal — Zaire's list) are never
  retrieved as examples.
- Refresh monthly; this file stays human-readable and directly editable. Only Zaire
  promotes a corpus-generated version into the repo.
